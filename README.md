## 🚀 Featured Projects
 
| Project | Stack | What it does |
|---|---|---|
| [**Sentinel**](https://github.com/kmodabber/Sentinel) *(team)* | Python, NFStream, Grafana | ML intrusion detection that scores live network flows. I built the pipeline turning PCAPs into flow features (validated against CICIDS2017), the sensor's PCAP flow export, and the tcpreplay demo setup. |
| [**Packet_Sniffer**](https://github.com/Hossane/Packet_Sniffer) | C++ | Packet capture and traffic analysis, working at the protocol level. *(in progress)* |
| [**FIM-tool**](https://github.com/Hossane/FIM-tool) | Go, SHA-256, SQLite | File integrity monitor: stores hash baselines in SQLite, scans directories with include/exclude rules, classifies changes and writes JSON reports with severity levels. |
| [**Password-manager**](https://github.com/Hossane/Password-manager) | Python, Fernet, Docker | CLI password manager using AES-128 (Fernet) with HMAC-SHA256, bcrypt master password checks and PBKDF2 key derivation (100k iterations). Containerized with Docker. |
| **Secure Audit System** | C++, Qt, GoogleTest | Desktop app for time-limited document access, backed by a hash-chained, append-only, fail-closed audit log. |
| [**Number-detection-AI**](https://github.com/Hossane/Number-detection-AI) | Python | Handwritten digit recognition with image processing and ML classification. |
